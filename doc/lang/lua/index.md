# Lua

## Style guide 

[Style guide](http://lua-users.org/wiki/LuaStyleGuide) in short:

Indentation
: two spaces

Line length
: 80 characters

Naming
: Variables: `lowercase_with_underscore`
: functions: `function functionName()` (not `functionName = function()`)
: modules: `lowercase_with_underscore`

Quoting
: single quoting
