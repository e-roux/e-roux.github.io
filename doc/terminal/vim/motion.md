# Motion

The last motion commands can be repeated with <kbd>;</kbd>

## Jumps

A "jump" command normally moves the cursor several lines away.
The following commands are "jump" commands: "'", "`", "G", "/", "?", "n", "N",
"%", "(", ")", "[[", "]]", "{", "}", ":s", ":tag", "L", "M", "H" and the
commands that start editing a new file.

<kbd>CTRL-O</kbd> and <kbd>CTRL-I</kbd> go the older and newer position in the jump list. `:ju[mps]` prints that list, `:cle[arjumps]`.
